# ApiClient-DLL

Uma biblioteca .NET projetada para facilitar a comunicação com APIs REST, utilizando tecnologias modernas para manipulação de chamadas HTTP e integração assíncrona.

## Recursos

- Suporte para chamadas HTTP simplificadas (GET, POST, PUT, DELETE).
- Uso de bibliotecas confiáveis como **RestSharp** para gerenciar requisições.
- Compatibilidade com o framework .NET 4.8.
- Configuração para execução em modo de depuração e produção.
- Registro para interoperabilidade COM, permitindo integração em aplicativos que suportem bibliotecas COM.

## Requisitos

- .NET Framework 4.8.
- Dependências incluídas:
  - RestSharp (versão 112.1.0)
  - Microsoft.Bcl.AsyncInterfaces
